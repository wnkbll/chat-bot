Чат-бот для вопросов и ответов

Разработать консольного чат-бота, который отвечает на заранее заданные вопросы. Запись
содержит информацию об ответах и вопросах.
Функциональность:
• Добавление, редактирование и удаление вопросов и ответов
• Поиск ответа на введенный вопрос
• Вывод всех доступных вопросов
• Сохранение и загрузка данных из файла
