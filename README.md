## Чат-бот для вопросов и ответов  

Разработать консольного чат-бота, который отвечает на заранее заданные вопросы. Запись
содержит информацию об ответах и вопросах.  

### Функциональность  
 - [x] Добавление, редактирование и удаление вопросов и ответов  
 - [x] Поиск ответа на введенный вопрос  
 - [x] Вывод всех доступных вопросов  
 - [x] Сохранение и загрузка данных из файла  

### Сборка проекта
Требования:  
`gcc>=14.2.0`  
`python>=3.13`  

Для сборки исопльзуется скрипт `build.py`. Из корневой директории выполнить команду `python3 build.py`. По оконачанию сборки будет сгенерирована директория `build`, содержащая исполняемый файл `chat`. Он будет запущен автоматически после сборки.

### Команды
```
/add "question" "answer"
Добавляет новый вопрос и ответ на него. Если такой вопрос уже есть, то предлагает обновить его.

/update "question" "answer"
Обновляет ответ на существующий вопрос, если такой вопрос существует.

/remove "question"
Удаляет вопрос и ответ на него, если такой вопрос существует.

/list
Вывод все вопросы и ответы на них.

/exit
Выходит из чата.
```
